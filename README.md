## 📖 About the Project

Retro Snake is a classic arcade-inspired snake game that recreates the nostalgic gameplay experience enjoyed by generations of players. The objective of the game is simple: control the snake, collect food to grow longer, and achieve the highest score possible while avoiding collisions with walls and the snake's own body.

Built using modern web technologies, the game combines the timeless mechanics of the original Snake game with a clean and responsive user interface. As the player progresses, the snake grows in length, increasing the difficulty and challenging the player's reflexes and strategic thinking.

This project was developed as a fun and interactive way to practice game development concepts, event handling, collision detection, score management, and responsive user interface design.

## 🎯 Gameplay

1. Start the game.
2. Use the arrow keys to control the snake.
3. Eat food to increase your score and grow the snake.
4. Avoid colliding with walls.
5. Avoid colliding with your own body.
6. Try to achieve the highest score possible.
